# Contributing

Contributions that improve source accuracy, methodology, accessibility or reproducibility are welcome.

For an evidence correction, provide:

1. the `EVD-NNNNNN` record ID;
2. the exact disputed statement or field;
3. a primary or peer-reviewed supporting source;
4. the proposed correction;
5. any relevant date or licence limitation.

Do not submit secrets, private correspondence, scraped personal profiles or unsupported predictions. A pull request that changes `data/current/` must also include a valid, matching `release-manifest.json` and pass the public validator.
